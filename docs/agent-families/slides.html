  • Better skill-cap thresholding via vector-based retrieval
  • Auto-learns engineering skills and company tribal knowledge
  • Learns from a simulated human — or a real one
  • Auto-integrates into a normal Claude Code user's flow
  • All manually orchestrated DAG factories are special cases of this algorithm

Research extension · what context actually does

Training writes the skills · context selects the skill

the model
p(y | q) = ∑θ p(y | q, θ) · p(θ)
add context C
p(y | q, C) = ∑θ p(y | q, θ) · p(θ | C)
training edits
p(y | q, θ) — the skills
context edits
p(θ | C) — which skill is in play
fine-tuning rewrites the library·a prompt sharpens the posterior over it
θ a latent task / skill (learned in pretraining) C the context q query p(θ | C) posterior — concentrates as C grows
ICL works with random labels ⇒ selection, not learning — Min 2022 · Xie 2021 (Bayesian view) · Hendel 2023 (task vectors) · Petrov 2024 (elicitation ceiling)
