From the attention patch to a gradient step

Slide 22 ends at the in-context patch \(\color{#E0863B}{\Delta W}_{\mathrm{ctx}}=\sum_i \color{#3E7BD6}{v_i}\otimes\color{#3FB97E}{k_i}\), then drops \(\color{#E0863B}{\Delta W}_{\mathrm{GD}}\) beside it. This fills the gap: first earn \(\color{#E0863B}{\Delta W}_{\mathrm{GD}}\) from a loss, then find exactly when the two are equal.

W weights x, k, y input · key · label v, e value · error signal

Part A — what one gradient step actually is

Take the same linear model, \(\hat y=\color{#E0863B}{W}\color{#3FB97E}{x}\), and train it on the examples \((\color{#3FB97E}{x_i},\color{#3FB97E}{y_i})\) with squared loss:

\[ \mathcal L(\color{#E0863B}{W})=\tfrac12\sum_i\big\|\,\color{#E0863B}{W}\color{#3FB97E}{x_i}-\color{#3FB97E}{y_i}\,\big\|^2. \]

Differentiate. The gradient is a sum of outer products:

\[ \nabla_{\!\color{#E0863B}{W}}\,\mathcal L=\sum_i(\color{#E0863B}{W}\color{#3FB97E}{x_i}-\color{#3FB97E}{y_i})\,\color{#3FB97E}{x_i}^{\top}. \]

Name the bracket the error signal (the residual — how wrong the model is on example \(i\)):

\[ \color{#3E7BD6}{e_i}\;=\;\color{#E0863B}{W}\color{#3FB97E}{x_i}-\color{#3FB97E}{y_i}\qquad\Longrightarrow\qquad \nabla_{\!\color{#E0863B}{W}}\mathcal L=\sum_i \color{#3E7BD6}{e_i}\,\color{#3FB97E}{x_i}^{\top}. \]

One gradient-descent step (rate \(\eta\)) is \(\color{#E0863B}{W}\leftarrow\color{#E0863B}{W}-\eta\,\nabla\mathcal L\), so the update is:

\[ \color{#E0863B}{\Delta W}_{\mathrm{GD}}\;=\;-\eta\sum_i \color{#3E7BD6}{e_i}\otimes\color{#3FB97E}{x_i}. \]

(Fold the \(-\eta\) into \(\color{#3E7BD6}{e_i}\) and this is the slide's \(\sum_i \color{#3E7BD6}{e_i}\otimes\color{#3FB97E}{x_i}\) — the same \(\color{#3E7BD6}{\sigma_i}=-\eta\,\color{#3E7BD6}{e_i}\) that appeared on slide 21.)

The thing to notice: \(\color{#3E7BD6}{e_i}=\color{#E0863B}{W}\color{#3FB97E}{x_i}-\color{#3FB97E}{y_i}\) depends on the label \(\color{#3FB97E}{y_i}\). The error signal is target-aware — it knows the right answer. Hold that thought.

Part B — line the two up, term by term

\[ \begin{aligned} \text{attention patch:}&\qquad \color{#E0863B}{\Delta W}_{\mathrm{ctx}}=\sum_i \color{#3E7BD6}{v_i}\otimes\color{#3FB97E}{k_i}, \qquad \color{#3E7BD6}{v_i}=\color{#E0863B}{W}_{\!V}\color{#3FB97E}{x_i},\ \ \color{#3FB97E}{k_i}=\color{#E0863B}{W}_{\!K}\color{#3FB97E}{x_i}\\[4pt] \text{gradient step:}&\qquad \color{#E0863B}{\Delta W}_{\mathrm{GD}}=\sum_i \color{#3E7BD6}{e_i}\otimes\color{#3FB97E}{x_i}. \end{aligned} \]

The colours already show the correspondence: green slot \(\leftrightarrow\) green slot (key ↔ input), blue slot \(\leftrightarrow\) blue slot (value ↔ error). The two matrices are equal term-by-term exactly when both slots match:

\[ \underbrace{\color{#3FB97E}{k_i}=\color{#3FB97E}{x_i}}_{\text{green: easy}} \qquad\text{and}\qquad \underbrace{\color{#3E7BD6}{v_i}=\color{#3E7BD6}{e_i}}_{\text{blue: the whole question}}. \]

Green slot (easy). \(\color{#3FB97E}{k_i}=\color{#E0863B}{W}_{\!K}\color{#3FB97E}{x_i}=\color{#3FB97E}{x_i}\) just needs \(\color{#E0863B}{W}_{\!K}=I\) (the key carries the input). No problem.

Blue slot (the real work). We need the value to compute the residual:

\[ \color{#3E7BD6}{v_i}=\color{#E0863B}{W}_{\!V}\color{#3FB97E}{x_i}\;\overset{!}{=}\;\color{#3E7BD6}{e_i}=\color{#E0863B}{W}\color{#3FB97E}{x_i}-\color{#3FB97E}{y_i}. \]

But \(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{x_i}\) is a fixed projection of the example — it has no \(\color{#3FB97E}{y_i}\) in it. For the value to equal \(\color{#E0863B}{W}\color{#3FB97E}{x_i}-\color{#3FB97E}{y_i}\), two things must hold:

  1. the token must carry the label \(\color{#3FB97E}{y_i}\) — i.e. each in-context example is an \((\text{input},\text{label})\) pair, not just an input; and
  2. \(\color{#E0863B}{W}_{\!V}\) must be arranged to output prediction \(-\) label.

Part C — the construction that makes it exact

This is the von Oswald / Dai construction. Stack each context token as the pair \((\color{#3FB97E}{x_i},\color{#3FB97E}{y_i})\); choose \(\color{#E0863B}{W}_{\!K}\) to read the input and \(\color{#E0863B}{W}_{\!V}\) to compute the residual. Then \(\color{#3E7BD6}{v_i}=\color{#3E7BD6}{e_i}\), and:

\[ \color{#E0863B}{\Delta W}_{\mathrm{ctx}}=\sum_i \color{#3E7BD6}{v_i}\otimes\color{#3FB97E}{k_i} \;=\;\sum_i \color{#3E7BD6}{e_i}\otimes\color{#3FB97E}{x_i}\;=\;\color{#E0863B}{\Delta W}_{\mathrm{GD}}. \]

One attention pass over the prompt \(=\) one gradient step on the in-context loss. Trained toy transformers converge to exactly this on in-context regression.

Part D — the honest caveat

For a generic free-text prompt there is no label \(\color{#3FB97E}{y_i}\), so \(\color{#3E7BD6}{e_i}\) isn't even defined and \(\color{#3E7BD6}{v_i}\) is just a projection. Then \(\color{#E0863B}{\Delta W}_{\mathrm{ctx}}\) and \(\color{#E0863B}{\Delta W}_{\mathrm{GD}}\) share the form \(\sum(\cdot)\otimes(\cdot)\) but are not the same matrix. Same shape, different content — the equality is a property of the construction, not of every prompt.

So, in one breath

A gradient step is \(\sum_i \color{#3E7BD6}{e_i}\otimes\color{#3FB97E}{x_i}\) where \(\color{#3E7BD6}{e_i}\) is the label-aware residual. The attention patch is \(\sum_i \color{#3E7BD6}{v_i}\otimes\color{#3FB97E}{k_i}\). The keys already match the inputs; the only question is whether the value computes the residual. Arrange the tokens as \((\text{input},\text{label})\) pairs and the value to output prediction\(-\)label, and the two become identical. Otherwise they only rhyme.
