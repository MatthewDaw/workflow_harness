The identity you’re missing

A matrix times another matrix’s transpose equals the sum of the outer products of their columns. For two \(d\times N\) matrices \(A=[a_1\ \cdots\ a_N]\) and \(B=[b_1\ \cdots\ b_N]\):

\[ A\,B^{\top} \;=\; \sum_{j=1}^{N} a_j\,b_j^{\top}. \]

Check on a single entry \((r,c)\):

\[ (A B^{\top})_{rc} = \sum_{j} A_{rj}\,B_{cj} = \sum_{j} (a_j)_r\,(b_j)_c = \sum_{j} (a_j b_j^{\top})_{rc}. \quad\checkmark \]

This is the same outer-product fact that built the trained weights on slide 21 (\(\color{#E0863B}{W}_T=\color{#E0863B}{W}_0+\sum_i \color{#3E7BD6}{\sigma_i}\color{#3FB97E}{x_i}^{\top}\)) — here it runs in reverse: a matrix product unpacks into a sum of outer products.

Step 1 — regroup line 1 as “build a matrix, then apply it to \(\color{#3FB97E}{q}\)”

Matrix multiplication is associative, so bracket line 1 as the effective matrix first:

\[ F(\color{#3FB97E}{q})=\Big[\,(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{P})(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{P})^{\top}\,\Big]\,\color{#3FB97E}{q} \qquad\text{(a } d\times d \text{ matrix, then } \times\,\color{#3FB97E}{q}\text{)} \]

Apply the identity with \(A=\color{#E0863B}{W}_{\!V}\color{#3FB97E}{P}\) (columns \(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{p_j}\)) and \(B=\color{#E0863B}{W}_{\!K}\color{#3FB97E}{P}\) (columns \(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{p_j}\)):

\[ (\color{#E0863B}{W}_{\!V}\color{#3FB97E}{P})(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{P})^{\top} = \sum_{j=1}^{N}(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{p_j})(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{p_j})^{\top}. \]

So attention over the whole prompt is a sum, over every prompt token \(\color{#3FB97E}{p_j}\), of (its value) \(\otimes\) (its key):

\[ F(\color{#3FB97E}{q})=\sum_{j=1}^{N}(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{p_j})(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{p_j})^{\top}\,\color{#3FB97E}{q}. \]

Still line 1 — just one outer-product term per token.

Step 2 — split the prompt’s columns into base + demos

The prompt \(\color{#3FB97E}{P}\) is just columns. Cut them into two groups:

\[ \color{#3FB97E}{P}=\big[\;\underbrace{\color{#3FB97E}{p_1}\ \cdots\ \color{#3FB97E}{p_{N_0}}}_{\text{base / instructions}} \;\big\|\; \underbrace{\color{#3FB97E}{x_1}\ \cdots\ \color{#3FB97E}{x_m}}_{\text{in-context examples}}\;\big] \]

The sum over all tokens splits into base tokens plus demo tokens:

\[ F(\color{#3FB97E}{q})= \underbrace{\sum_{j\in\text{base}}(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{p_j})(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{p_j})^{\top}}_{\textstyle \text{call this } \color{#E0863B}{W}_{\mathrm{ZS}}}\,\color{#3FB97E}{q} \;+\; \sum_{i\in\text{demos}}(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{x_i})(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{x_i})^{\top}\,\color{#3FB97E}{q}. \]

Step 3 — name the base part \(\color{#E0863B}{W}_{\mathrm{ZS}}\)

The first sum doesn’t involve the examples at all — it’s the fixed matrix you’d get from the base prompt alone (no demonstrations). That is the “zero-shot” model, so name it \(\color{#E0863B}{W}_{\mathrm{ZS}}\):

\[ \color{#E0863B}{W}_{\mathrm{ZS}}=\sum_{j\in\text{base}}(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{p_j})(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{p_j})^{\top}. \]

Substitute the name, and you have line 2 exactly:

\[ F(\color{#3FB97E}{q})=\color{#E0863B}{W}_{\mathrm{ZS}}\,\color{#3FB97E}{q}+\sum_{i}(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{x_i})(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{x_i})^{\top}\,\color{#3FB97E}{q} \]

The whole connection in one sentence

Attention over the prompt is a sum of one (value \(\otimes\) key) term per token (the matrix identity); split those tokens into base + examples, and the base terms collapse into a fixed matrix \(\color{#E0863B}{W}_{\mathrm{ZS}}\) while the example terms stay as an explicit sum — which is line 2.

That leftover example-sum, \(\sum_i(\color{#E0863B}{W}_{\!V}\color{#3FB97E}{x_i})(\color{#E0863B}{W}_{\!K}\color{#3FB97E}{x_i})^{\top}\), is the patch \(\color{#E0863B}{\Delta W}\) — a weight matrix with the same outer-product shape as a gradient step \(\big(\color{#E0863B}{\Delta W}_{\mathrm{GD}}=\sum_i \color{#3E7BD6}{e_i}\otimes \color{#3FB97E}{x_i}\big)\).
